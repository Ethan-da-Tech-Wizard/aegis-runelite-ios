## 1. Architectural Overview

RuneLite Mobile brings desktop RuneLite's plugin ecosystem to iOS devices as a **real, native, standalone client architecture** built specifically for Apple Silicon and iOS security sandboxing.

### Core Systems Engineering:
* **Native C++ & Metal Client Operation:** Analyzes and interfaces directly with the official OSRS iOS client engine (`OldSchoolRunescape.app`), which runs as an ARM64 Mach-O executable with an Apple Metal rendering pipeline (`CAMetalLayer`, `MTLCommandBuffer`, `MTKView`).
* **Swift Plugin Engine Port:** Complete clean-room port of the RuneLite engine in Swift (`RuneLiteCore`), featuring an event bus (`GameTickEvent`, `StatChangedEvent`, `MenuEntryAddedEvent`), 3D perspective projection math (`Perspective.swift`), and coordinate systems (`WorldPoint`, `LocalPoint`).
* **Jagex Third-Party Client Compliance:** Strictly enforces Jagex's official published guidelines:
  - **1:1 Input Ratio:** 1 physical touch gesture = at most 1 game interaction. No macroing, click buffering, or automated tap synthesis.
  - **Zero De-Rendering:** Never removes fog, walls, trees, or geometry to provide unfair vantage points.
  - **Additive Metal Overlays:** Renders HUD overlays using additive Metal passes that leave the underlying game graphics and depth buffers intact.
* **Zero-Credential Architecture:** Authenticates exclusively through Jagex's official Identity Provider using OAuth2 with PKCE via Apple's `AuthenticationServices.ASWebAuthenticationSession`. The app **never** sees, stores, logs, or transmits user passwords or 2FA codes. Refresh tokens are stored in the iOS Keychain with biometric access control (`kSecAccessControlBiometryAny`).
* **Anti-Detection & Account Safety:** The client maintains 100% telemetry and packet signature integrity. Touch events are physically generated by the user's digitizer (measuring `majorRadius`, capacitance, pressure, and velocity). The overlay reads game state and never injects or alters server packets.

## 4. Sideloading Instructions for iPhone & iPad

You can install RuneLite Mobile onto your Apple device without a jailbreak using any of the following methods:

### Method A: AltStore (Recommended for Most Users)
1. Install [AltServer](https://altstore.io) on your Mac or Windows PC.
2. Connect your iPhone to the computer via USB or Wi-Fi sync.
3. Open AltStore on your iPhone and tap **My Apps** > **+**.
4. Select `RuneLiteMobile.ipa` (or the injected `OSRS_RuneLite_Sideload.ipa`).
5. AltStore will sign the application with your free Apple ID and install it.
6. AltServer automatically refreshes the 7-day certificate wirelessly over home Wi-Fi!

### Method B: SideStore (Untethered On-Device Signing)
1. Install [SideStore](https://sidestore.io) on your iPhone using the one-time pairing file.
2. In SideStore, activate the local WireGuard VPN loopback.
3. Tap **+** and select `RuneLiteMobile.ipa`.
4. The app signs and refreshes directly on your device without ever needing a PC again!

### Method C: TrollStore (Permanent Signing - iOS 14.0 to 16.6.1 / 17.0)
1. If your device is running a TrollStore-supported iOS version, open the TrollStore app.
2. Tap **Install from File** and select `RuneLiteMobile.ipa`.
3. TrollStore signs the app with CoreTrust root entitlements:
   - **No 7-day expiration** (installed permanently).
   - **No 3-app limitation**.
   - Full JIT support enabled out of the box!

### Method D: Apple Developer Certificate (Xcode)
1. Open `RuneLiteMobile.xcodeproj` in Xcode on macOS.
2. Select your development team under **Signing & Capabilities**.
3. Select your connected iPhone as the run destination.
4. Press `Cmd + R` to build, sign, and install directly to your device with a 1-year certificate.

## 6. Security & Policy Attestation

RuneLite Mobile was architected strictly following Jagex's official third-party client statements. By design:
- It **never simulates touch input** (all touches pass from physical fingers through standard UIKit).
- It **never records or stores passwords** (authentication uses Jagex's official OAuth2 web interface).
- It **never de-renders geometry** or provides unfair combat automation.
- It **never alters network packets or anti-cheat telemetry**, ensuring 100% account safety.
